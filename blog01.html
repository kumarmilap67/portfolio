Using Particles.js to Add Stunning Interactive Backgrounds
You can just add lightweight cool particle animations to your web pages!
By Milap August 21, 2024 • 5 min read

What is Particles.js?

Particles.js is a lightweight JavaScript library that creates animated particle systems (dots, lines, bubbles, etc.) using the HTML5 <canvas> element. It is often used to create subtle — or bold — interactive backgrounds for landing pages, portfolios, and hero sections.

Why use it on a blog?

  • It adds a modern, dynamic feel without changing your content layout.
  • It’s easy to configure with a JSON file — no heavy animation knowledge required.
  • Works well as a background layer behind readable content when you add a translucent card.

Quick setup — files you need

Minimal project structure (static site):

/
├─ index.html
├─ style.css
├─ script.js
└─ particles.json

Include the library

For a simple static page, use the CDN in your HTML before your script:

<script src="https://cdn.jsdelivr.net/npm/particles.js"></script>
<script src="script.js"></script>

particles.json — sample config

Place this next to your HTML and load it via particlesJS.load() (this file controls how the particles behave):

{
  "particles": {
    "number": { "value": 80 },
    "color": { "value": "#00bcd4" },
    "shape": { "type": "circle" },
    "opacity": { "value": 0.5 },
    "size": { "value": 3 },
    "line_linked": {
      "enable": true,
      "distance": 150,
      "color": "#00bcd4",
      "opacity": 0.4,
      "width": 1
    },
    "move": { "enable": true, "speed": 3 }
  },
  "interactivity": {
    "events": {
      "onhover": { "enable": true, "mode": "repulse" },
      "onclick": { "enable": true, "mode": "push" }
    }
  },
  "retina_detect": true
}

Initialize in JavaScript

Create script.js and load the config:

particlesJS.load('particles-js', 'particles.json', function() {
  console.log('Particles.js loaded.');
});
Tip: If you open the HTML directly using file:// in some browsers, the JSON may fail to load due to CORS. Use Live Server or a simple local http server (Python's python -m http.server) instead.

Design & accessibility tips

  • Keep contrast high — place text inside a translucent card or overlay so readability stays strong.
  • Performance — reduce the particle count on mobile or disable interactivity for smaller screens.
  • Respect motion preferences — consider turning off particle motion when prefers-reduced-motion is set.

Example: disable on small screens

if (window.matchMedia('(max-width: 720px)').matches) {
  // either load a lighter config or skip initializing particles
}

Customization ideas

  • Change particle shapes (triangle, polygon or image) for branding.
  • Sync particle color with your site accent color for a cohesive look.
  • Use the repulse mode for mouse hover, or grab to create a connecting lines effect.

Alternatives & when to choose them

If you need advanced features, 3D particles, or more active maintenance, consider:

  • tsparticles — modern fork with support for frameworks (React, Vue, Angular) and more features.
  • Three.js — for WebGL-powered 3D particle systems (higher learning curve).

Final checklist before publishing

  • Test performance on low-end devices and reduce particle count if needed.
  • Verify readability and accessible contrast across sections.
  • Ensure JSON loads correctly from your hosting environment (no CORS issues).

Ready to start? Copy the example files into your VS Code project, run a local server (Live Server recommended), and tweak the particles.json values until you hit a look that matches your brand.
